# RouteSense MVP

RouteSense 是一个面向对话式业务平台的价值感知 AI 模型路由演示。它先判断当前请求应该澄清、检索、调用工具还是规划，再选择达到质量门槛的最低模型档位；若质量检查失败，则保留上下文自动升级。网站界面使用简体中文。

## 当前版本包含

- 旅游推荐多轮对话与 5 个稳定演示场景；
- 用户阶段、信息完整度、任务复杂度、个性化、实时需求、风险、业务价值 7 类标签；
- `clarify`、`retrieve_memory`、`search`、`call_tool`、`plan`、`answer`、`handoff` 策略；
- 小模型、通用模型、强推理模型 3 个可配置逻辑档位；
- 硬约束检查、失败升级、成本、Token、延迟和执行轨迹；
- 100 条合成旅游任务的全小、全强、动态路由三组实验；
- 成功率、约束满足率、单次成功任务成本与 P95 延迟对比；
- 原始路由日志和 300 条实验结果导出；
- 原 AgentScope 证据核验、覆盖率、合并/拆分、新发现和严重程度评测的资产入口说明。

用户记忆、搜索和业务数据目前采用可复现的本地模拟。模型回答支持两种模式：

- 配置模型服务环境变量后，调用真实模型；
- 未配置密钥时，自动使用演示回答。

这样既能稳定演示产品闭环，也不会把模拟结果描述成真实业务转化。

## 安全填写 API

不要把 API Key 写入 `RouteSenseApp.tsx`、浏览器代码、`NEXT_PUBLIC_` 变量或网页输入框。浏览器会把这些内容暴露给访问者。

项目已经准备好本地私密配置文件 `.env.local`。用记事本打开它，把值粘贴到等号后面：

```text
ARK_API_KEY=你的 API 密钥

# 暂时只有一个模型时，只填这一项：
ARK_MODEL=你的模型ID

# 要真实比较三个档位时，改为分别填写：
ARK_MODEL_SMALL=轻量模型ID
ARK_MODEL_GENERAL=通用模型ID
ARK_MODEL_REASONING=强推理模型ID

ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3/responses
```

`.env.local` 已被 Git 忽略，不会进入代码仓库。`.env.example` 只保存空白模板。

填写完成后重新启动网站。页面右上角从“演示模式”变为“真实模型已连接”，即表示配置生效。

真实调用链为：

```text
浏览器 → RouteSense 服务端接口 → 服务端读取 API Key → 模型服务
```

API Key 不会被返回给浏览器，也不会进入导出的路由日志。

## 本地打开

需要 Node.js 22.13 或更高版本。第一次运行：

```bash
pnpm install
pnpm dev
```

页面会显示本地访问地址。生产构建和验收：

```bash
pnpm test
```

## 关键边界

- 评估集和实验数字为合成演示数据；
- 请求风险 `risk_level` 决定路由安全门槛；
- 原用研痛点严重程度 `severity` 评价分析结果，两者分开计算；
- 当前规则路由不是自研路由算法，不代表生产级高并发或真实转化提升；
- 路由配置页中的名称是中文显示名；真正的模型 ID 只从服务器环境变量读取；
- 部署到线上时，API Key 必须配置为托管平台的服务端密钥，不能提交 `.env.local`。
